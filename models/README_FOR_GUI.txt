🛡️ PhishGuard ViT - ملفات الموديل النهائي الجاهز للـ GUI

هذا المجلد يحتوي على النموذج النهائي بعد اكتمال التدريب على الـ GPU 
(تم حفظ أفضل نسخة من Epoch 9 بدقة 91.89% على مجموعة الـ Test).

📁 محتويات المجلد:
-----------------
1. model.safetensors        <- أوزان الموديل الأساسية (سريعة وآمنة)
2. best_model.pt            <- أوزان PyTorch الأصلية
3. config.json              <- ملف إعدادات النموذج ومعمارية الـ ViT
4. preprocessor_config.json <- إعدادات معالجة وتجهيز الصور (224x224)
5. predict_gui.py           <- كود بايثون جاهز للاستدعاء داخل أي واجهة مستخدم

------------------------------------------------------------------------
🚀 طريقة الاستخدام في كود الواجهة (GUI Code):
------------------------------------------------------------------------
يمكنك استدعاء الموديل في أي واجهة (Tkinter, PyQt, Streamlit, Gradio) كالتالي:

from predict_gui import PhishDetector

# 1. إنشاء الـ detector مرة واحدة عند فتح البرنامج
detector = PhishDetector()

# 2. فحص أي صورة عند الضغط على زر في الواجهة
result = detector.predict("مسار_الصورة.png")

# 3. النتائج المتاحة:
print(result["label"])         # 'phishing' أو 'legitimate'
print(result["confidence"])    # نسبة الثقة (مثلاً 99.8%)
print(result["is_phishing"])   # True أو False
print(result["probabilities"]) # تفاصيل احتمالية كل فئة
