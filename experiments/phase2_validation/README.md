# Phase 2 Stage 1: non-destructive diagnostics

This experimental area is intentionally isolated from the original project state.

Goal:
- Audit records for duplicates, overlapping identities, and domain leakage risk.
- Produce a traceable report without changing dataset, notebook, or model artifacts.
- Keep all findings reproducible and explicit about what is confirmed vs. unverified.

Files created here are separate from the project root and do not overwrite source artifacts.
